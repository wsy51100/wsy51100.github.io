Course Project

Robot Pose Estimation using Implicit Neural SDF Maps

Pipeline

  • Raw RosBag2 LiDAR scans are segmented by timestamps.
  • Ground-truth poses are generated from KISS-SLAM initialization and Bundle Adjustment refinement.
  • Each scan is registered against an implicit neural SDF map using field residuals and gradients.
  • The same formulation supports localization on a prebuilt map and online incremental mapping.

System pipeline. Each scan is preprocessed and registered to an implicit map to estimate Ti, which is then used to initialize the next frame via a constant-velocity prior. In the online mode, the refined pose and scan are further used to incrementally update the implicit map (left branch). In the localization mode (red arrow), scan-to-map registration is performed against a fixed prebuilt implicit map, and the mapping/update branch is skipped.

Evaluation Design

  • Round 1 was used to construct the reference implicit map.
  • Round 2 was tracked against the prebuilt map from a provided initial pose.
  • Pose quality was assessed using Absolute Trajectory Error and Relative Pose Error.

Interpretation

After initialization, tracking remains locally stable. Most residual errors are short disturbances rather than persistent drift.

The full course report documents a complete LiDAR-based robot pose estimation and neural implicit mapping workflow, including self-recorded robot data collection, implicit SDF map construction, scan-to-map registration, pose tracking evaluation, and mapping quality assessment.

Key evidence shown

  • Self-recorded Clearpath Husky A200 + Hesai XT32 LiDAR dataset with two trajectory rounds.
  • Implicit neural SDF mapping pipeline using LiDAR ray sampling, shallow MLP decoding and marching cubes mesh extraction.
  • Scan-to-map pose tracking with constant-velocity initialization, voxel downsampling.
  • Evaluation using APE/RPE for localization and odometry, plus Accuracy, Completeness, F-score and Chamfer-L1 for mapping quality.
